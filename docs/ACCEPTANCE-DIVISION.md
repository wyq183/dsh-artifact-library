## B 栏 · 只能人看（每条：看什么 → 怎么算过）

### B1 布局与视觉（我的断言只验「CSS 里有这条规则」，不验肉眼效果）
- **看什么**：目录列表行高是否一致、长文件名是否**真的出省略号**（不是撑破）、图标与文字颜色是否协调。
- **算过**：滚动时行高不跳动；超长名字末尾是 `…` 且**不换行**。
- ⚠️ **#5/#10 只保证「规则存在」，不保证「生效」** —— CSS 写对了但被别的规则覆盖是可能的。

### B2 浮层几何（我明确没钉「布局质量」）
- **看什么**：右键菜单 / Ctrl+P 浮层，在**窗口最右、最下、最左上**四个角落分别打开。
- **算过**：**不越出视口、不贴边（留 8px）、该翻上去时翻上去**。
- ⚠️ **#20 只验「夹取/翻转的计算存在且经 `placeMenu`」，不验结果对不对**（这是布局相关，我当时明确没钉）。

### B3 交互手感（机器只能验「结构在不在」）
- **多选**：`Ctrl+点击`切换、`Shift+点击`区间、空格切换、`Ctrl+A`全选、`Esc`清空。
  **算过**：五条都灵，且选中行有明显高亮。
- **hover 操作区**：鼠标移入行 → 操作按钮出现。**算过**：**出现时行高不变化**（这是关键，行高一变虚拟滚动就算错）、不遮挡文件名。
- **批量条**：选中后出现在**列表上方**。**算过**：滚动列表时**它不跟着滚走**。
- **面包屑**：点「编辑路径」→ 回车跳转、`Esc` 取消。**算过**：两条都对，且非法路径的报错来自宿主（不是自编文案）。
- **拖入登记**：从资源管理器拖文件进面板。**算过**：有投放提示；真登记成功。**取不到路径时要明说做不到**（不许假装成功）。
- **拖出去引用**（task-13）：把一行拖到输入框。**算过**：输入框里真的出现引用/`@path`。

### B4 缩略图
- **看什么**：图片正常出缩略图；**故意让一张图加载失败**（后端 500）。
- **算过**：失败后**不留空洞** —— 自动退到官方端点，再失败退成**类型图标**，且**不反复重试**。
- ⚠️ §11.3 我验的是「两段 URL 的语义」，**没验真机上的观感**。

### B5 画廊虚拟滚动（低阈值 60）
- **看什么**：画廊切成 200 项，滚动。
- **算过**：**流畅、不卡顿、不留白块**、滚到底能看到最后一项。
- ⚠️ 我验的是「阈值常量 + 只渲染 24 个方块 + 撑高容器」，**不验流畅度**。

### B6 设置面板「真的生效」★（今晚 UI 改动最多的地方）
- **看什么**：打开设置 → 改 `密度`、`默认视图`、`列开关`、`卡片尺寸`、`缩略图大小`、`虚拟滚动阈值` → **回到列表/画廊看**。
- **算过**：**每改一项，界面上立刻有对应变化**；刷新后**保持**。
- ⚠️ **#26 只保证「源码里读了这些键」，不保证「读对了、算对了、看起来对」**。
  历史上这里出过真事故：**9 个键「只存不读」**，面板看着全对、改了什么都不发生。

### B7 新手引导（回答「东西去哪了」）
- **看什么**：清空产物库时首次打开。
- **算过**：文案讲的是「**你让 AI 做的东西会自动收在这**」+ 有**真能点**的下一步；**不是弹窗**；筛选为空时**不**误触发引导。

### B8 产物右键菜单（task-13 新建）
- **看什么**：右键产物行。
- **算过**：菜单出现、**「在文件夹中显示」真的打开资源管理器并选中该文件**（不是打开文件夹而已）。
- 端点侧 `POST /files/reveal` 已就绪（`revealRow()`，client.js:3792）。
