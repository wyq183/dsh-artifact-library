## 没做（按优先级）

### 1. 物理整理（第 2 批）⚠️ 最要紧

**现状**：472 条记录散在 **180 个目录**。

```
25 条  C:\HarmonicaTools          ← 根目录直接躺 25 个
23 条  C:\HarmonicaTools\三角洲口琴工作台
20 条  C:\Users\Administrator\.dsh
19 条  C:\Users\Administrator\.dsh\scratch   ← 临时目录
```

**核心问题**：插件**没有移动用户文件的能力**。
`fs.renameSync` 只有 2 处，都是写自己的数据文件。

⇒ 「整理」在这个插件里永远是**逻辑字段**：
数据库说"这条属于 XX 目录"，磁盘上文件还在原地。

**为什么没做**：移动用户文件是**不可逆操作**，必须先出方案让主人确认。

### 2. 视频封面 ⚠️ 主人明确提过

主人：「视频也应该有视频封面展示吧」

**环境已确认**：ffmpeg 8.1.2 在 PATH 里。

**方案**：
- `GET /files/cover?path=` —— 抽一帧转 JPEG，落盘缓存（按 mtime 失效）
- 前端 `previewHtml` 对 `video/*` 用封面，失败回落图标
- ⚠️ **必须异步**：抽帧几百毫秒，不能卡住列表渲染
