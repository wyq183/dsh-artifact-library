## 一、为什么必须人工截

本插件是**宿主 UI 插件**：面板由 DSH 主窗口通过官方席位（`sidebar.panellist` + `main`）渲染，
样式全部读宿主设计 token，因此**长得像 DSH 本身**。

这意味着截图**无法**在无头浏览器 / 静态页面里复现——`ui/index.html` 是**兜底管理页**（旧形态），
拿它截图会与用户实际看到的面板**不一致**，属于事实性错误。所以：

- ❌ 不要用 `ui/index.html` 截图冒充面板
- ❌ 不要用 `~/.dsh/scratch/*.png` 里的历史调试图
- ✅ 必须开真实 DSH Web GUI，点左侧栏 🐋「产物库」，再截

## 三、每张图具体截什么

### 1. `01-directory.png` — 目录视图

**怎么到那**：左侧栏 🐋「产物库」→ 顶部视图切换 → **「目录」** → 展开到至少第二层。

画面里必须能看清（这几项正是 v0.7.0 的卖点，别裁掉）：

- [ ] **面包屑路径**在顶部（行内不复读路径——这是本版的关键设计）
- [ ] 行是**紧凑行高**（32px），不是旧版 110px 的大卡片
- [ ] **按类型着色的文件图标**（文件夹琥珀色 / 代码 DeepSeek 蓝 / 图片紫 …）
- [ ] 目录在前、文件在后，且显示 **「N 项」**
- [ ] 列：文件名 · 大小 · 修改时间，数值右对齐
- [ ] 悬停某一行时**操作按钮出现**（打开 / 定位 / 登记）

⚠️ 截之前**确认窗口够宽**（≥1200px），否则列被挤掉，看起来像半成品。

### 2. `02-search.png` — 文件搜索

**怎么到那**：同一面板 → 视图切换 → **「文件」** → 首次点「启动文件索引」，等就绪 → 输入关键词。

必须体现：

- [ ] 搜索框里有**真实的 Everything 语法**（例如 `ext:md path:项目`），占位符不算
- [ ] **命中条数**和**索引范围**在界面上如实显示（这是隐私卖点，别裁）
- [ ] 至少 3 条**跨目录**的命中结果，**两行式**（文件名 + 次级路径）
- [ ] 一行 hover 出的「登记」按钮

⚠️ **不要**截索引还没就绪的「启动中」画面 —— 那是等待态，不是能力展示。
⚠️ 图上**不要**出现真实私人路径。用工作区/示例目录，或事后**整行打码**（不要整张涂黑）。

### 3. `03-cards.png` — 卡片视图

**怎么到那**：面板视图切换 → **「卡片」** → 鼠标悬停或点开一条带图片/文本的产物。

必须体现：

- [ ] ≥4 张产物卡片：**标题 + 摘要 + 项目 + 标签**（证明 AI 精化真的填进去了）
- [ ] 至少一张有**缩略图预览**
- [ ] **星级**控件可见（有打过分）
- [ ] 顶部**统计条**（总数 / 待精化 / 项目数）

⚠️ 卡片内容若含隐私，替换成示例数据，**不要**只做马赛克。
